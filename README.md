# SmartCart — E-Commerce Website

## Project Overview
SmartCart is a sample e-commerce website developed to demonstrate Object-Oriented Programming (OOP) concepts and three behavioral design patterns.

## Technologies Used
- HTML
- CSS
- JavaScript (ES6 Classes)
- Git and GitHub
- GitHub Pages

## Design Patterns Implemented

### 1. Observer Pattern
Notifies subscribed customers when a product's price decreases.

### 2. Strategy Pattern
Allows customers to select UPI, card, or wallet payment strategies dynamically. Payments are simulated for demonstration purposes.

### 3. Command Pattern
Encapsulates shopping cart actions such as adding items, removing items, and applying coupons. Supports undo and redo functionality.

## OOP Concepts
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Composition
